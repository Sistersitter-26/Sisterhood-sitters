# Sisterhood Sitters Website

This is a complete starter website for Sisterhood Sitters.

## Before publishing
1. Open `alisonphillip09@gmail.com`.
2. Change:
   alisonphillip09@gmail.com
   to the email address that should receive booking requests.
3. Open `index.html` in a browser to preview the site.

## Files
- index.html — website content
- style.css — design and responsive layout
- script.js — mobile menu and booking form

## Free publishing
You can publish these files using a free static hosting service such as GitHub Pages, Netlify, or Cloudflare Pages.

## Important
The booking form currently opens the visitor's email app. For a true online form that stores submissions without opening email, connect the form to a form service or backend before launch.
